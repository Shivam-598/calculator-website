# calculator-website

🧮 Calculator Website

A simple and responsive calculator web application built to perform basic arithmetic operations. This project is ideal for learning and demonstrating front-end development skills including HTML, CSS, and JavaScript.

## 🚀 Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Responsive UI for desktop and mobile screens
- Keyboard input support (optional depending on your implementation)
- Clear and backspace functions

## 🛠️ Tech Stack

- **HTML** – for markup structure  
- **CSS** – for styling and layout  
- **JavaScript** – for calculator logic and interactivity

## 📁 Project Structure

```
calculator-website
│
├── index.html       # Main HTML file
├── style.css        # Stylesheet
└── script.js        # JavaScript logic
```

## 🧑‍💻 Getting Started

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/Shivam-598/calculator-website.git
   ```
2. Navigate to the project directory:
   ```bash
   cd calculator-website
   ```
3. Open `index.html` in your browser.
